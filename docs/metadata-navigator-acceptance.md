## Результат целиком

Один WebviewView объединяет заголовок с настоящим именем конфигурации, пиктограммы,
постоянное поле поиска и виртуализированное дерево. Отдельные views поиска,
фильтров и помощи убраны; старые focus-ID поиска/фильтров оставлены совместимыми.
Отбор открывается временной вкладкой. Существующее дерево данных, TreeItem,
поиск/состав отбора, SVG/overlays, XML-операции и редакторы не переписаны.
Команды и палитра используют общий порт selection/event/reveal.

[Доказательства gate, архитектура, снимки и границы проверки](metadata-navigator-webview.md).
Предыдущий отчёт о native TreeView заменён этой актуальной версией; историческое
исследование API сохранено отдельно, с отметкой нового разрешения.

## Что изменилось

- `package.json`, `registerMetadataView.ts`: один renderer и необходимые адаптеры;
  реальное имя через прежний контракт свойств, сохранение состояния по проекту.
- `metadataNavigatorModel/View/Menu/Title`: ограниченные DTO/ID/epoch, lazy paging,
  восстановление пути к выбору, прежние меню, защита от устаревших действий.
- HTML/CSS/JS: viewport, мышь/клавиатура/ARIA, CSP, безопасный текстовый DOM.
- `metadataFilterView.ts`: прежний отбор в WebviewPanel, сброс, проверка сообщений,
  отмена таймера и подписок; вычисление состава отбора осталось прежним.
- У команд и палитры изменён только тип порта представления.
  Автооткрытие по настройке осталось однократным и только для 1С-проекта.

## Проверки и остаток приёмки

Обязательные команды и точный новый Actions VSIX перечислены в body PR.
Тесты проверяют DTO, адресацию, stale epoch/selection, unknown ID/command,
страницы 20 000 узлов, выбор за первой сотней, существующие контексты меню,
маршрутизацию и ограничения операций, поиск/отбор, стартовый жизненный цикл.

поиск по имени/синониму, множественный отбор и родители/потомки, контекстное меню,
клавиатуру, синхронизацию палитры и редактирование свойств, формы/макеты,
расширения/поддержку, смену проекта и перезапуск, обычную папку, узкую панель,
светлую/тёмную тему. Автоматические проверки не заменяют этот полный GUI-паритет.
